# URL Shortener

A full-stack URL shortening backend built with Java, Spring Boot, MySQL, and REST APIs.

## Features

- Create shortened URLs
- Generate unique short codes
- Custom URL aliases
- URL validation
- URL expiration
- Click tracking
- URL analytics
- Duplicate alias protection
- Global exception handling
- API rate limiting
- MySQL database persistence

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST API
